#  London Houses Price Analysis Dashboard (Excel)

An interactive Excel dashboard that analyzes London housing data to explore property prices, features, and value drivers using data cleaning, feature engineering, KPIs, and visual analytics.

---

##  Dataset
Source: Kaggle  
Rows: 1001  
Columns: 18  

### Main Features:
- Bedrooms
- Bathrooms
- Square Meters
- Property Type
- Interior Style
- Heating Type
- Materials
- View
- Price (£)

##  KPIs & Insights
The dashboard answers questions like:
- How price changes with number of bedrooms
- Which interior styles are more expensive
- Impact of materials on house value
- Heating type effect on pricing
- View & property type influence on price
